# UNT Course Manager (CSCE 3420)

Intro page, Major Course Catalog (Feature 1), and Degree Path (Feature 2).

## Run it
Open `index.html` in a browser. No install needed.

## Files
- `index.html` - the three pages (Home, Catalog, Degree Path)
- `css/style.css` - styling
- `js/data.js` - sample course data (edit here)
- `js/app.js` - page logic (saves the plan in the browser for now)
